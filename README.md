# studentu_laika_plānotājs
Sistēma domāta studentiem, lai palīdzētu plānot brīvo laiku un atrast laka momentus, ko vēltīt papildus mācībām.
Sistēmas galvenās funkcijas:
1. Sistēma piekļūst studenta Google kalendāram izmantojot API
2. Apstrādā studenta kalendāra saturu
3. Atrod brīvos laika momentus
